## 🆓 New Free Features (Sabke liye — No Subscription)

> Yeh features sabko milenge, inse user base badhega aur engagement improve hoga.

### 🌐 Multi-Language Romanization
- **Japanese Romanization** — Japanese lyrics ko romaji mein convert karo
- **Chinese Pinyin** — Chinese characters ko pinyin mein dikhao
- **Thai Romanization** — Thai script ko readable English mein convert karo
- Users ko dropdown se language select karne ka option do

### 🎤 Karaoke Mode
- Active lyrics ko **word-by-word highlight** karo (line-by-line ke bajaye)
- Real-time sync ke saath ek bouncing ball style indicator
- Users feel karein jaise karaoke machine chal rahi hai

### 📸 Lyrics Screenshot / Share
- Current lyrics ka ek **beautiful card/image generate** karo with album art background
- One-click **copy to clipboard** ya direct social media share (Instagram stories, Twitter, WhatsApp)
- Watermark ke saath branding bhi ho jayegi

### 🔤 Font Customization (Basic)
- **Font Size** adjust karne ka slider (small / medium / large / extra large)
- **Font Weight** — Light, Regular, Bold
- **2-3 free fonts** milenge (e.g., Inter, Poppins, Roboto)

### 🎨 Pre-made Themes (Basic Pack)
- 5-6 free themes jaise:
  - 🌙 **Midnight Dark** — deep dark with subtle blue
  - 🌅 **Sunset Vibes** — warm orange-pink gradient
  - 🌊 **Ocean Breeze** — cool blue-green tones
  - ⚡ **Neon Night** — bright neon on black
  - 🤍 **Minimal White** — clean white background
- One-click apply karo, koi manual color picking nahi

### 🔄 Lyrics Alignment Options
- Left align, Center align, Right align toggle
- Line spacing / padding adjust karne ka control

### ⌨️ Keyboard Shortcuts
- `Alt + L` — Lyrics page toggle
- `Alt + G` — Glow on/off
- `Alt + T` — Theme cycle karo
- `Alt + S` — Screenshot lyrics

### 🌍 Lyrics Translation (Basic)
- Current lyrics ke neeche **English translation** dikhao (using free translation APIs)
- Hindi, Spanish, French jaise popular languages support karo

### 🎬 Animated Backgrounds (Pro)
- **Album art blur background** — current song ka album art ko blur karke background mein dikhao
- **Particle effects** — floating musical notes, stars, bubbles
- **Video backgrounds** — looping ambient videos (rain, space, city lights)
- **Reactive visualizer** — background music ke beat ke saath react kare

### 🎨 Custom Theme Builder (Pro)
- Fully custom **theme editor** — har cheez customize karo:
  - Background gradient (multi-color, direction, speed)
  - Text shadow, text outline
  - Blur intensity
  - Custom animation speed
- **Import/Export themes** — apne themes share karo community ke saath
- **Save unlimited themes** (free mein sirf 2-3)

### ✍️ Premium Fonts Library (Pro)
- **50+ premium fonts** unlock karo (Google Fonts + custom handwriting fonts)
- **Custom font upload** — apna font .ttf/.woff file upload karo
- **Text effects** — rainbow text, typewriter effect, neon text, 3D text

### 🎤 Advanced Karaoke Mode (Pro)
- **Dual language display** — original + romanized/translated simultaneously
- **Sing-along scoring** — microphone se input leke accuracy score do (gamification)
- **Karaoke party mode** — shareable link se friends ke saath sync mein gaao

### 📝 Custom Lyrics Editor (Pro)
- Kisi bhi song ke lyrics **manually edit** karo
- Agar lyrics galat hain ya missing hain toh **khud type karke save** karo
- **Sync editor** — timestamps set karo manually for perfect sync
- Community contributed lyrics database

### 🎵 Lyrics Spotify Overlay / Mini Player (Pro)
- Ek **floating mini widget** jo har tab ke upar dikhaye lyrics
- Picture-in-Picture style — chhota sa window jisme lyrics scroll hote hain
- Kahi bhi kaam karte waqt lyrics dekh sako bina Spotify tab pe jaaye

### 📊 Listening Stats & Insights (Pro)
- **Most viewed lyrics** — kon se gaane ke lyrics sabse zyada dekhe
- **Top artists** — lyrics usage ke basis pe
- **Weekly/Monthly report** — listening patterns
- **Mood analysis** — lyrics ke sentiment se mood track karo

### 🎭 Mood-Based Themes (Pro)
- AI se lyrics ka **mood detect** karo (happy, sad, romantic, energetic)
- Automatically **theme change** ho mood ke basis pe:
  - Sad song → dark blue tones with rain particles
  - Happy song → bright warm colors with confetti
  - Romantic → pink/red gradients with hearts
  - Energetic → neon colors with pulse effects

### 🔗 Spotify Playlist Integration (Pro)
- Lyrics ke through **discover similar songs**
- "Songs with similar lyrics" recommendation
- Auto-create **mood-based playlists** from lyrics analysis

### 🎙️ Live Lyrics Sync Fix (Pro)
- Agar lyrics out of sync hain toh **manual offset adjust** karo (+/- seconds)
- **Auto-sync correction** using audio fingerprinting
- Community-verified sync timestamps

### ☁️ Cloud Sync & Backup (Pro)
- Saari settings, custom themes, edited lyrics **cloud mein sync** ho
- Kisi bhi device pe login karo, sab settings wahi milein
- Cross-browser support (Chrome, Firefox, Edge)

### 🚫 Ad-Free Experience (Pro)
- Free version mein chhote non-intrusive banners ya prompts dikhao
- Pro mein **completely ad-free** clean experience

## 💡 Subscription Implementation Notes

### How to Gate Features:
1. **Chrome Storage** mein user ka subscription status save karo
2. **Backend server** (Firebase / Supabase) se license verify karo
3. **Stripe / Razorpay** integration for payments
4. Free users ko premium features pe **🔒 lock icon** dikhao with "Upgrade to Pro" button

### Monetization Strategy:
- Free tier bahut accha rakho — users khush rahein aur recommend karein
- Pro features genuinely advanced hone chahiye — value for money feel ho
- **7-day free trial** do Pro ka — taste de do users ko
- **Referral program** — refer karo, 1 month free Pro paao
