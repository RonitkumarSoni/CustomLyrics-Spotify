# LyricsPlus privacy information

LyricsPlus version 1.1.4 works on `https://open.spotify.com/*` and reads visible lyrics on the Spotify lyrics page to display a pronunciation line. It also reads the current song's cover image URL to color the lyrics background. The extension stores your settings in Chrome extension sync storage so they can follow your Chrome profile where sync is available.

This release does not ask you to sign in, collect analytics, use the microphone, or send lyric text to a LyricsPlus server or a translation service. It does not store your listening history or lyric text. Pronunciation runs in the packaged extension on your device. Spotify remains responsible for its own website and data handling.

You can turn off enhancement in the popup. You can remove stored settings through Chrome by uninstalling the extension. For privacy questions, use the repository's [issue tracker](https://github.com/dupitydumb/LyricsPlus-Spotify/issues) without posting personal information. A public hosting URL for this notice must be set in the Chrome Web Store listing before submission.
